# 🌍 World Population Analysis Dashboard

### 📊 Explore • Visualize • Analyze • Discover

An interactive **multi-page data analytics dashboard** built with **Python, Streamlit, Pandas, and Plotly** to explore global population data through interactive visualizations, statistical analysis, and data-driven insights.

The dashboard analyzes population data including:

**Country • Continent • Historical Population • Area • Density • Growth Rate**

This enables both **historical analysis** and **cross-country comparisons**.

# ⚙️ Run Locally

```bash
# Clone the repository
git clone https://github.com/Sukhman126/World-population-Analytics.git

# Install dependencies
pip install -r requirements.txt

# Run the dashboard
streamlit run Home.py
```

🌐 Open: `http://localhost:8501`
